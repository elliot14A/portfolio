# help.txt                                    portfolio editor reference

Everything below is bound the way it is bound in my real config.
Press <Space> at any time to see the leader menu.

## Navigation

  h j k l        move left / down / up / right
  w b e          word forward / back / end
  0 ^ $          start of line / first non-blank / end of line
  gg G           top / bottom of buffer
  <C-d> <C-u>    half page down / up

## Buffers

  <S-l>          next buffer
  <S-h>          previous buffer
  <S-q>          close buffer
  <leader>bb     alternate buffer
  :e <file>      edit a file

## Finding

  <leader>ff     find files
  <leader>fg     live grep
  <leader>fb     buffers
  /              search in buffer
  n N            next / previous match
  <Esc>          clear highlights

## Windows

  <leader>|      vertical split
  <leader>-      horizontal split
  <C-h/j/k/l>    move between windows
  <leader>wd     close window

## Misc

  <leader>e      toggle file tree
  <C-\>          toggle terminal
  :help          this file
  :q             close buffer

Not every mapping is implemented yet. The ones that aren't will tell you so
rather than doing nothing.
