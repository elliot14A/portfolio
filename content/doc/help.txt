# help.txt                            portfolio editor keymap reference

This editor mirrors my real Neovim setup, but only some of it is wired up here.
Everything listed below actually works. Press <Space> for the leader menu, type
: for the command line, / to search.

## Commands ( : )

  :e <file>      open a file, e.g. :e README.md
  :e #           open the alternate (previous) buffer
  :bn  :bp       next / previous buffer
  :b <n>         open buffer number n
  :bd  :q        close the current buffer
  :<number>      jump to a line, e.g. :42
  :noh           clear the search highlight
  :help          this file
  :Neotree       toggle the file tree
  :Alpha         back to the start screen

Unknown commands answer with E492, the way nvim does.

## Search ( / )

  /text          search the buffer, jump to the first match
  <Esc>          clear the highlight

## Leader ( <Space> )

  <Space>e             toggle the file tree
  <Space>ff            find files (telescope)
  <Space>fb            find buffers (telescope)
  <Space>bb  <Space>`  alternate buffer
  <Space>bd            close the buffer

The popup lists a few more bindings from my real config; those aren't wired up
here, and they say so when you pick them.

## Motion

  h j k l        left / down / up / right
  w  b           word forward / back
  0  ^  $        start / first non-blank / end of line
  gg  G          top / bottom of buffer
  <C-d>  <C-u>   half page down / up
  5j             counts work on any motion

## Buffers

  <S-l>  <S-h>   next / previous buffer
  clicking a tab or a tree entry opens it

Buffers are read-only, so :w answers with E45. Every file renders as the raw
markdown source with treesitter colours, the way nvim shows it.
